## 🎯 当前重心

- 改进 `python-office` 的模块化设计和开发者体验
- 扩展自动化测试、示例和跨平台文档
- 为文档、电子表格、PDF、图片和 OCR 构建专注的工具包
- 将常见的自动化需求转化为可复用的开源组件
- 让初学者更容易理解和使用 Python 自动化

## 🛠️ 我在做什么

- **办公自动化** —— 减少常见文档格式的重复工作
- **小巧专注的包** —— 保持单个功能的可复用性和可维护性
- **实用示例** —— 展示完整的工作流程，而非孤立的代码片段
- **学习资源** —— 帮助更多开发者从脚本走向可靠工具
- **开源基础设施** —— 改进发布、测试、文档和贡献工作流
