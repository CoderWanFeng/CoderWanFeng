## 🎯 Current Focus

- Improving the modular design and developer experience of `python-office`
- Expanding automated tests, examples, and cross-platform documentation
- Building focused packages for documents, spreadsheets, PDFs, images, and OCR
- Turning common automation needs into reusable open-source components
- Making Python automation easier for beginners to understand and adopt

## 🛠️ What I Build

- **Office automation** — reduce repetitive work across common document formats.
- **Small, focused packages** — keep individual capabilities reusable and maintainable.
- **Practical examples** — show complete workflows instead of isolated code snippets.
- **Learning resources** — help more developers move from scripts to reliable tools.
- **Open-source infrastructure** — improve releases, testing, documentation, and contribution workflows.
